# Наши путешествия

Готовый сайт: ничего собирать и устанавливать не нужно.

## Как выложить на GitHub Pages
1. На github.com нажми **New repository**. Назови, например, `travels`, выбери **Public**, нажми **Create repository**.
2. На странице репозитория нажми **uploading an existing file**. Перетащи в окно **всё содержимое этой папки** (index.html, остальные .html, папку assets и файл .nojekyll), затем **Commit changes**.
3. Открой **Settings → Pages**. В блоке *Build and deployment* выбери Source: **Deploy from a branch**, Branch: **main** и папку **/(root)**, нажми **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/travels/`. Эту ссылку можно отправлять друзьям.

## Как править
Открой нужный файл на GitHub (например `italy-2026.html`), нажми карандаш, измени текст и нажми **Commit changes**. Сайт обновится сам. Фото лежат в `assets/img`.

## Что где
- `index.html` — главная, `ideas.html` — идеи
- `italy-2026.html`, `north-spain-2025.html`, `iceland.html`, `baikal.html`, `egypt.html` — поездки
- `assets/` — стили, скрипты и фото
